Changelog: AIB Camera

1.3.1 (10 November 2026)

  • Android / zoom: 1× / 2× / 4× chips use expo-camera’s linear mapping (zoom 0–1 × an assumed ~8× device max), so 2× and 4× no longer look like 1× / ~2× on typical devices.
  • iOS / zoom: mapping aligned to expo-camera’s exponential curve; zoom logic extracted into useCameraZoom.
  • Map: simplified Leaflet/WebView; HOT tiles with a larger keep-buffer, load-after-zoom, and retry; fewer GPS injects while panning.
  • Map button label Maps (was “Open in Maps”).
  • Tab bar uses dark frosted glass (blur + dark wash, light icons); on Android below API 31, opaque wash only (no unstable native blur).
  • Photos gallery: within each day, captures sort newest → oldest (latest shot top-left); map “Save as photo” stamps the save time, not a stale GPS tick.

1.3.0 (8 November 2026)

  • Video on Camera: Photo / Video toggle, clips up to 60 s with optional microphone (muted if mic is denied).
  • Stamp burned into the MP4 (same layout as photos) after stop; if overlay fails, the unstamped clip is kept (needs a native rebuild with Nitro / video-pipeline).
  • Gallery and viewer: JPEG poster (frame or placeholder) + Video badge, in-app playback, share/delete MP4 like photos.
  • Permissions: microphone and video media-library access; fresh native rebuild required.

1.2.2 (8 November 2026)

  • Current wind on the stamp (Camera and Map): speed and direction from Open-Meteo for the effective point (Me or Aimed).
  • Wind toggle in Stamp settings; local cache; omitted offline; shutter never waits on the network request.
  • Altitude on the stamp without the “a.s.l.” / «s.l.m.» suffix (meters only).
  • Place on the stamp: wider wrap (typically at most 2 lines).
  • Aim sheet label: Distance (no “(m)”; the m suffix stays on the field).
  • Aimed target: removed the 50 km distance cap (typed distance and map drag).

1.2.1 (7 November 2026)

  • Unified map: Leaflet + OpenStreetMap HOT on iOS and Android (no Apple Maps / Google Maps SDK; no API key). Dark mode no longer uses CARTO (their tiles require a key since 2026).
  • Taller map with the same live stamp overlay as Camera (replacing the separate info card).
  • Map actions: Copy, Open in Maps, Save as photo (map + pins + stamp into the in-app gallery, same path as a camera shot).
  • Gallery: 3 columns in portrait, 5 in landscape.
  • Photos permission requested early after Camera (like Location), to sync the «AIB Camera» album.
  • Light theme: clearer camera chrome and tab selection; zoom chip black (light) / white (dark).
  • Android zoom: correct mapping to the device max zoom; 1× / 2× / 4× chips and more reliable pinch.
  • Aimed target: distance presets 1 / 2 / 5 / 10 km; custom meters field with an m suffix; larger pin touch target for dragging.
  • Coordinate format in stamp settings (N/E, decimal, DMS), alongside date format.

1.2.0 (5 November 2026)

  • Map tab: live map of the effective point (Me or Aimed), with stamp-parity location lines, copy/share, and open in the system Maps app.
  • Aimed red pin is draggable on the map; on drop, meters and bearing update from live GPS.
  • Same Aim sheet from Camera and Map.
  • Photo viewer with swipe between shots and a bottom filmstrip (share/delete the current shot).

1.1.0 (3 November 2026)

  • Device rotation support (portrait and landscape).
  • Adaptive letterbox viewfinder: in landscape, controls move to the side rails.
  • Compass heading on the stamp is corrected for screen orientation so it tracks the camera in landscape.
  • Fix for the expo-screen-orientation dependency in native builds.

1.0.2 (3 November 2026)

  • Shared floating glass tab bar on iOS and Android (expo-blur), replacing iOS-only native liquid glass.
  • Solar Linear icons unified on both platforms.
  • Updated Android adaptive icon.

1.0.1 (29 October 2026)

  • Aimed target: distance (presets or custom meters) + GPS + compass to estimate coordinates of what you point at; stamp label “Aimed target (estimated)”.
  • English UI selectable in Settings (Italian remains the default).
  • Terms of use published on the site.
  • Share multiple images from the gallery.
  • GPS/compass/place improvements: heading accuracy gate, circular smoothing, stickier place labels.
  • PolyForm Noncommercial license, privacy/store URLs, and local build/submit flow.

1.0.0 (23 October 2026)

First public release.

  • Field camera with letterboxed viewfinder and live stamp (date/time Europe/Rome, GPS, altitude, heading, place, custom text).
  • Stamp burned into the JPEG (Skia) and best-effort EXIF (capture ID, GPS, JSON UserComment).
  • In-app gallery as source of truth; optional Photos album “AIB Camera”.
  • On-device capture log (UUID) with CSV export; install ID in Settings.
  • Stamp field toggles in Settings; pinch-to-zoom on the viewfinder.
  • Offline-first, no account or cloud sync; shutter works without GPS.
  • Expo SDK 58, brand icon and splash.
